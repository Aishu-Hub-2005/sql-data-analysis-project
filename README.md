# E-Commerce Customer Churn Analysis Using SQL

📌 Project Overview

This project analyzes an e-commerce customer dataset using MySQL to identify customer churn patterns, customer behavior, and factors associated with customer retention.

The project demonstrates practical SQL skills including data exploration, data cleaning, filtering, aggregation, joins, subqueries, and business-oriented analysis.

 🎯 Business Objective

The main objectives of this project are to:

- Analyze customer churn patterns
- Identify customer segments with higher churn
- Understand customer purchasing behavior
- Analyze customer activity and engagement
- Generate insights that can support customer retention strategies

 📊 Project Analysis

The SQL queries analyze the available customer and transaction data to understand:

- Customer churn

- Customer segmentation

- Factors related to customer retention

 💡 Key Findings

The analysis was used to identify patterns in customer behavior, purchasing activity, and churn.

Key areas analyzed include:
